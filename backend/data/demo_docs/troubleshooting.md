# SupportMesh troubleshooting handbook

## App crashes

If the app crashes repeatedly, work through these steps:

1. Check that the device has enough storage (at least 500MB free)
2. Clear the app cache: Settings -> Apps -> SupportMesh -> Clear cache
3. Confirm the app is on the latest version (currently v2.0.3)
4. If none of the above helps, uninstall and reinstall

## Login problems

### 401 authentication failed
- Confirm the username and password are correct
- Check whether caps lock is on
- Try the "Forgot password" flow to reset it
- If signing in with a third-party provider, confirm the authorization has not expired

### 403 insufficient permissions
- Confirm the account is not suspended
- Check that you are within the permitted IP range
- Contact an administrator to confirm the permission configuration

## Payment problems

### Payment failed
- Confirm the card has sufficient funds
- Check that online payments are enabled on the card
- Try a different payment method
- On a credit card, confirm the single-transaction limit has not been exceeded

### Double charge
- Do not submit the order again
- Confirmed double charges are refunded automatically within 24 hours
- If nothing has been returned after 24 hours, contact support with the order number

## Network problems

### Slow page loads
- Check that the network connection is working
- Try switching between Wi-Fi and mobile data
- Clear the browser cache
- Try a different browser

### Connection timeout
- Check whether a VPN is in use (some VPNs interfere with the connection)
- Try restarting the router
- On a corporate network, confirm the firewall is not blocking it
